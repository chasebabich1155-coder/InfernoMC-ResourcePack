# InfernoMC resource pack

The resource pack the InfernoMC server sends players, hosted here so every player can download it
(Minehut only allows packs from a few hosts, raw.githubusercontent.com among them).

`packs/<sha1>.zip` is each version of the pack, named after its SHA-1. The server (PrisonCore,
`modules.pack.mirror`) sends players the one matching the pack built into the plugin, and serves the
pack itself if it isn't here yet.
